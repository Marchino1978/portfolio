======================================================
  QUICK START GUIDE - ESP32 DEMO FIRMWARE
======================================================

1. RENAME FILES (Mandatory):
   Before opening the project, remove ".example" from file names:
   
   - ETF.example.ino      --> ETF.ino
   - config.example.h     --> config.h
   - language.example.h   --> language.h
   - market.example.json  --> market.json

2. CONFIGURE CREDENTIALS:
   Open "config.h" and insert your WiFi network credentials 
   and your JSON URL.

3. COMPILE:
   Open "ETF.ino" in Arduino IDE, select your ESP32 board, and upload!
